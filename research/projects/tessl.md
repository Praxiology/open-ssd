# Tessl

**Research status:** Official product landing page reviewed; technical source review pending  
**Documentation:** [Tessl](https://tessl.io/)  
**Accessed:** 2026-11-03

## Observed Evidence

- The official landing page describes Tessl as a software-factory platform centered on versioned context and repeatable agent workflows.
- The official documentation describes managing skills/plugins as versioned dependencies with discovery/install/rollback; skill review/security scoring and policy/RBAC controls; before/after skill impact evaluation on task scenarios; session-activation insights; SCM-wide drift/overlap inspection; and an open-beta conversational platform agent.
- Its “improving a skill” tutorial explicitly separates format/quality review from behavior evaluation, and describes comparing agent results with and without the skill.
- The installation docs describe a Tessl CLI and authentication/update lifecycle. These are product documentation statements, not independently tested results.
- The landing page did not expose a confirmed first-party GitHub source link during this review. Several guessed GitHub repository names were unavailable, so none is treated as authoritative.

## Preliminary Relevance

The stated focus on versioned context and repeatable workflows aligns with the SSD goals, but it is not enough to evaluate artifact schemas, runtime, or actual agent integrations.

## Limitations

Product docs were inspected, but implementation code, evaluation validity, exact support matrix, security controls, and roadmap status remain unverified.
